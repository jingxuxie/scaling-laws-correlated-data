\section{Reproducibility Checklist}

\begin{itemize}[leftmargin=*]
    \item The exact risk is evaluated without stochastic optimization or
    matrix inversion.
    \item All random experiments use explicit seeds.
    \item Generated CSV and JSON summaries are retained with the code.
    \item A separate simulation stops trajectories at an exact raw horizon and
    validates Theorem~\ref{thm:raw-horizon}.
    \item The default experiment suite runs with $O(M)$ memory on a laptop.
    \item The official AAAI style files are intentionally not redistributed;
    the build automatically uses them when placed in the paper directory.
\end{itemize}
